# 📊 Dashboard de Análise de Vendas | Dashboard de Análisis de Ventas

## 🇧🇷 Português (Brasil)
Este projeto é um dashboard interativo desenvolvido em Python para análise de dados de vendas de um negócio de alimentação (Cafe&Marmitas). O objetivo é transformar dados brutos em insights acionáveis para a tomada de decisão, automatizando o cálculo de faturamento, identificação de produtos premium e visualização de métricas por categoria.

## 🇪🇸 Español
Este proyecto es un dashboard interactivo desarrollado en Python para el análisis de datos de ventas de un negocio de alimentación (Cafe&Marmitas). El objetivo es transformar datos crudos en información accionable para la toma de decisiones, automatizando el cálculo de ingresos, la identificación de productos premium y la visualización de métricas por categoría.

---

## 🛠️ Tecnologias / Tecnologías
- **Python 3.x**: Linguagem de programação base.
- **Pandas**: Manipulação e análise de dados (DataFrames, groupby, filtros).
- **Matplotlib**: Visualização de dados e geração de gráficos.
- **Streamlit**: Criação de interfaces web interativas para dashboards de dados.
